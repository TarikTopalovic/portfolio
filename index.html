    The flagship

    T.A.R.I.K., my own Jarvis

    A Linux desktop agent I use every day. I say or type what I want; it opens a Claude Code session and works the machine until the job is done, in its own browser, on my real screen when it has to, or as a team of parallel workers for big jobs.

    It runs on my PC and my home server, and I reach it from my phone. When it solves a chore, it saves the script, so the next time it runs the tool instead of rewriting it.
